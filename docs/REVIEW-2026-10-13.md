# Revisão incremental — 13/10/2026

## O que mudou

- Proteção de rascunhos também detecta alterações isoladas em data, conta, categoria e tipo, comparando o formulário com o estado de abertura.
- Cancelar edição passa pelo mesmo fluxo de confirmação de Escape e Fechar. Recusar mantém os campos; confirmar não grava o rascunho.
- Playwright preserva Edge como padrão no Windows e permite Chromium instalado pelo Playwright em Linux/macOS, mantendo a opção BOLSARIO_BROWSER_CHANNEL.
- README explica cancelamento, ambiente e execução multiplataforma; teste de regressão acrescentado em tests/interface.spec.cjs.

## Verificação desta revisão

Executado na nuvem com Node.js 24.19.0, sem arquivos no computador do usuário:

- npm ci --ignore-scripts com cache temporário: aprovado.
- npm run lint, npm run typecheck, npm test: aprovados; 16 testes financeiros.
- npm run build e npm run format:check: aprovados.
- Harness complementar com DOM sintético: aprovou alterações isoladas de conta/data/categoria/tipo, confirmação recusada/aceita e Cancelar edição sem gravações financeiras. Não substitui navegador real.
- Playwright: tentativa bloqueada no lançamento do Chromium pelo sandbox (socket não permitido). Nenhum cenário dessa execução deve ser considerado aprovado; a nova regressão está tipada, mas precisa rodar em navegador.
- Revisão visual, axe-core, screenshots e impressão PDF não foram reexecutados nesta revisão.

## Limites e continuidade

Preservados file://, chave pierre-finance-v1, formato bolsario.backup versão 2, regras monetárias, fonte/ícones locais e identidade visual. Nenhuma migração, integração financeira, alteração de dados reais, merge ou publicação manual. Esta é uma melhoria de interação e manutenção, não uma reformulação visual completa.

Antes de integrar, executar npm run test:browser e repetir com BOLSARIO_TEST_DIST=1; conferir teclado e ambos os temas. O histórico de validação anterior permanece em INTERFACE-VALIDATION.md e não foi reapresentado como resultado desta rodada.
